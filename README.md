# Hiral's Notes

A dark, phone-first, installable notes PWA: text + list notes, photo/video/audio/voice-note
attachments (IndexedDB), per-note PIN/pattern/emoji lock with playful fail screens,
28 aesthetic wallpapers, and on-device accounts (username + password + security-question
reset). All data stays on the device - no backend.

## Develop / build
npm install
npm run build   # outputs static site to dist/

## Deploy
dist/ is served by GitHub Pages (gh-pages branch).
